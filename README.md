# 詞語隨機生成器 (Auto Question Supply)

提供形容詞與名詞自訂儲存，並支援**不重複隨機組合**呈現 `(形容詞 的 名詞)` 的網頁應用程式。已設定完善，可一鍵部署至 **Vercel**。

## 🌟 核心功能特點

- **🎲 不重複抽取機制**：
  - 系統自動計算所有形容詞與名詞的組合池（例如 10 個形容詞 × 10 個名詞 = 100 種組合）。
  - 抽取過的組合**絕不重複出現**，並提供即時進度條與「剩餘未抽數量」百分比。
  - 當所有組合全數抽完時會發出貼心提醒。
- **🔄 靈活重置功能**：
  - **重置抽選池**：一鍵清空已抽取的紀錄，所有詞組重新洗牌、重新開始不重複抽取。
  - **清空詞庫**：提供一鍵清空所有形容詞與名詞功能，隨時從零自訂。
- **💾 詞庫保存與備份**：
  - **即時自動保存 (LocalStorage)**：任何新增、刪除動作皆自動即時保存至本機，重新整理或重啟瀏覽器絕不遺失。
  - **匯出備份 (JSON)**：一鍵下載保存目前所有詞庫檔案至本機電腦。
  - **匯入載入**：可上傳先前備份的 JSON 檔案，更換裝置或瀏覽器隨時無痛還原。
  - **批次輸入保存**：支援一次貼上多個形容詞與名詞（換行或逗點隔開）快速批量保存。
- **📋 實用工具**：
  - 一鍵複製生成結果 `(形容詞 的 名詞)`。
  - 最近 15 筆抽取歷史紀錄回顧。

## ⚡ 部署至 Vercel

本專案為輕量純靜態網站，並已包含 `vercel.json` 與 `package.json`，支援以下兩種方式秒級部署：

### 方法一：透過 GitHub 與 Vercel 連結（最推薦）
1. 將此專案推送（Push）至您的 GitHub 倉庫：`https://github.com/s411318-abc/auto-question-supply.git`。
2. 前往 [Vercel 官網 (vercel.com)](https://vercel.com/) 並登入。
3. 點擊 **"Add New..."** ➜ **"Project"**。
4. 選擇您的 GitHub 倉庫 **`auto-question-supply`**，點擊 **"Import"**。
5. 架構保持預設，直接點擊 **"Deploy"**！
6. 約 10 秒後即可取得上線網址（例如：`https://auto-question-supply.vercel.app`）。

### 方法二：透過 Vercel CLI 本地直接部署
在終端機中執行：
```bash
npx vercel
```
依照畫面提示完成登入與確認，即可直接部署上線。
